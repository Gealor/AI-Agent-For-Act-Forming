# ИИ-агент для формирования актов оказанных услуг

MVP версия ИИ-агента для изучения функционала LangChain/LangGraph, а также тест возможностей локальных LLM

# Как пользоваться?

1. Создайте .env файл со всеми необходимыми переменными (шаблон полей .env находится в .env.template)

2. В корневой папке создайте папку requisites

3. Поместите туда нужный документ с данными контр-агента

4. Добавьте путь до файла в список file_paths в скрипте main.

5. Запустите main.py при этом убедившись, что LLM по заданному в .env URL доступна
